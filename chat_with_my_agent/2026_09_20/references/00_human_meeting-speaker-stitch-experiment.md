## 討論 1：τ 能自適應嗎？

使用者問：「τ 能自適應嗎？」

Agent 提出三方案：

1. **平台期自動選 τ**（stability selection）：掃 τ 網格、找最寬「分區完全不變」
   平台期取中心。理由：親和度分布在 0.20–0.30 有天然斷層、τ≤0.30 結果相同，
   訊號乾淨、成本極低。
2. **每步合併自適應**（margin/ratio 制）：每輪凝聚時以 best/runner-up 比值或
   running mean−k·MAD 決定合併。對叢集規模變化敏感，但多一個超參。
3. **Permutation null**：重排組對建虛無分布，只合併超過 null 99 分位數者。
   理論最正確，成本較高。

先做 1。共識：τ 自適應只解「切在哪」，解不了「親和度被污染灌水」本身。

## 討論 3：τ 的語境解釋（使用者要求）

套用 explain-to-me skill（thing-explainer + analogy-engine）：

- 核心一句話：τ = 兩個語者叢集要合併，雙方投票親和度必須超過的最低門檻
- 比喻：兩個社團合併，雙方都要有 ≥τ 比例的成員投給對方，單方暗戀不算
- 關鍵語義變化：v3 的 τ 是 cosine 相似度刻度（0.55–0.90）、v3.1 的 τ 是
  投票親和度刻度（得票比例，0.30 左右）——同一符號換了尺
- 兄弟參數 δ（DELTA）：margin 低於 δ 不擋合併、只列入複查清單
- τ 在碼裡的位置：speaker_unify_v31.py 主迴圈 `best[0] <= tau → break`
